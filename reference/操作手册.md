# 操作手册 — 逐阶段命令与判读

> 入口与铁律见 `../SKILL.md`；**带完整输入输出的实例见 `../QUICKSTART.md`**；判据阈值见 `验收契约.md`。
> 这一页只写方法：每个阶段做什么、盯哪几行、看到什么就停。具体数字随零件变，不在这里抄。

命令里的占位符：`<pdf>` 图纸、`<总宽>` 图纸上的零件总宽（mm）、`<质量>` 图纸标注重量（kg）、
`<板厚>` 反算出的板厚、`<零件>` 零件号（产物文件名前缀）、`$R` 技能包根目录。

---

## 0 预检 `preflight`

先跑自检，一次确认环境齐备（只读，不开任何程序）：

```powershell
$R = "C:\path\to\pdf-to-3d-pipeline"
& "$R\run.ps1" preflight          # 等价于直接跑 scripts\selftest.ps1，但多一层 GATE 结论
```

看到 `RESULT: ready` / `GATE preflight: PASS` 才开工；`BLOCK` 项逐条修掉。
环境探测由 `scripts\env.ps1` 负责（python / pymupdf / AutoCAD / SolidWorks interop / 模板），
不依赖写死的用户名路径。

**不要用裸 `python`。** 本机 PATH 上的 `python` 是 Microsoft Store 的占位存根，执行直接
`exit 9009` 且没有任何报错——会让整条链路静默卡住。`env.ps1` 会自己找一个能真正执行的解释器，
也可以显式指定：

```powershell
$env:PDF3D_PYTHON = "C:\path\to\python.exe"
```

AutoCAD **必须开着**（replay 走 COM）；SolidWorks 不用提前开，脚本自己拉起，跑完自动关掉。

建工作目录，所有产物放这里，不要污染技能目录：

```powershell
$W = "$env:USERPROFILE\cad-agents\work\<零件>"
New-Item -ItemType Directory -Force $W | Out-Null
Set-Location $W
```

## 1 抄图注 `spec` → drawing_spec.json

**第一步就该做这个**，因为图纸上有一半信息只存在于文字里。

```powershell
& "$R\run.ps1" spec -Pdf .\part.pdf
```

输出一张孔表，逐条对照图纸看一遍：

```
数量    孔径    通/盲    面    沉孔
<n>    φ<d>   通孔/盲孔▽<深度>   正面/反面   ⌴φ<D>▽<深度>
...
孔位合计 <N> 个，写入 .\drawing_spec.json
call-outs=<条数>  holes=<N>  unparsed=0
GATE spec: PASS
```

判据两条：**`unparsed` 必须为空**，**`call-outs` 条数 = 图纸上的孔标注条数**。

脚本做的事：

- **φ / ⌴ / ▽ 不是文字，是矢量线**，按形状认：φ 是约 49 段线围成的闭环（6.9×8.3），
  ⌴ 是 3 段线组成的开口 U（约 16×8），▽ 是 4 段线（一条横线 + 一个向下的 V）。
- 文字词先按基线聚行，**再把符号挂到最近的一行**。符号框比字高，直接混在一起聚行会把
  上下两行图注粘成一行——那正是第一版脚本读不出沉孔、只能读到一行"φ6.6 通孔"的原因。
- `8×R3`、`12×R20` 这类过渡圆角、`15 X 35 贯穿` 这类腰形槽，单独记进 `other_callouts`，
  第 5 阶段用来把「圆角/槽端头的圆柱面」从孔里排除掉，避免误报。

**有读不懂的图注时脚本以非零退出**，并把原文打出来——那一刻必须人工读图补规则，不许带着它继续建模。
这条是防止"漏读"的唯一闸门：漏掉一条图注，后面所有数字都会自洽地错下去。

## 2 PDF → DWG `dwg`

先读图纸，记下：零件号、**材质**、**重量**、总尺寸标注、比例。
重量和材质是后面验收的唯一依据，不能漏。

```powershell
& "$R\run.ps1" dwg -Pdf .\part.pdf -PartWidth <总宽>
```

产出 `part.dwg` 和**同名 `.dxf`**（脚本自动 DXFOUT，不用另转），外加 `.log.txt`。

`-PartWidth` 是图纸上标注的零件总宽（mm），决定全局比例，错了后面全错。
图上没有总尺寸标注时，先按一个估计值跑，看阶段 3 输出的 `outer loop A x B` 与图纸比对，
不符再改这里重跑。

## 3 挑零件 `part`

```powershell
& "$R\run.ps1" part -Dxf .\part.dxf -Depth <板厚> -Mass <质量>
```

板厚还不知道就随便填，它只影响打印的估算值，几何提取与板厚无关。盯这几行：

```
outer loop  <A> x <B>  area <总面积> mm2
  window    <a> x <b>  area <窗口面积>
  ...
holes <n>  total area <孔面积> mm2
net area <净面积> mm2   volume @<板厚> = <体积> mm3   mass(6061) = <估算质量> kg
  mass <估算质量> kg vs drawing <质量> kg  (<偏差>%)
```

`outer loop` 是外轮廓，`window` 是内窗口，`holes` 是孔——逐项和图纸对一遍。
判据是「包住最多圆孔的最小闭合环」，不靠图层名猜，别人的图纸也能用。

两条硬判据：

- `outer loop` 必须等于图纸总尺寸。若是图框尺寸（例如 1740×1188），说明外轮廓没闭合或有多层套框。
- 质量偏差必须 ≤1%。超了就是几何挑错了，**回去修几何，不要调板厚凑数**。

> `holes` 数是**几何里的圆数**，一律按通孔计。盲孔的实际深度、沉孔的大直径段，
> 几何里都不存在——它们要靠阶段 4 的 `apply_spec` 补，阶段 5 才对得出来。

## 3b 定板厚 `thickness`（单视图没标板厚时）

```powershell
& "$R\run.ps1" thickness -Dxf .\part.dxf -Mass <质量> -Material aluminium
```

输出计算厚度和各标准板厚的对应质量，**取误差最小的规格**：

```
thickness     <t计算> mm   <-- computed
----------------------------------------------------------
candidates (closest stock sizes, mass they would give):
  t=<t1>  -> <m1> kg  (<偏差>)
  t=<t2>  -> <m2> kg  (<偏差>) OK
  t=<t3>  -> <m3> kg  (<偏差>)
----------------------------------------------------------
RESULT: use thickness <t2> mm (mass matches within 2%)
```

没有任何规格能复现图纸重量时，脚本会拒绝给结论——那说明几何抽错了，不是板厚问题。

材质密度：`--material aluminium|steel|stainless|brass|titanium`，或 `--density 0.0027`（g/mm³）。
定出板厚后用该值重跑阶段 3，让质量数可用于验收。

## 4 建模 `build`

```powershell
& "$R\run.ps1" build -Dxf .\part.dxf -Depth <板厚> -Name <零件> -Counterbore <正面沉孔深>
```

（等价于手跑 `part_segments.py` → `apply_spec.py` → `build_from_dwg.ps1`。）

`apply_spec.py` 按 `drawing_spec.json` 的**数量**去匹配几何里的圆，写两个字段：

| 字段 | 来历 | 例子 |
|---|---|---|
| `back_counterbores` | 「反面 ⌴φ11▽3.4」——DWG 里没有那圈 φ11 | 4 处 |
| `blind_holes` | 「▽5」——DWG 里画得和通孔一模一样 | 2×φ5 深 5 |

数量对不上它就以非零退出（「图注 4 处，可用光孔 0 个」），**不猜、不硬套**。
`-Counterbore` 只给**正面**沉孔（图纸 `⌴φ11▽3.4` 不写反面就是正面）。

`DwgBuild.cs` 不硬编码"正面沉孔深 + 反面沉孔深"，而是给每个轮廓/每个孔一个 **z 区间**，
板厚按所有端点自动切带，每带只画"整段都在这一带里"的元素：

```
band z<z0>~<z1>  (<n>个元素) segs=<n> -> ok 凸台-拉伸<k>
band z<z1>~<z2>  (<m>个元素) segs=<m> -> ok 凸台-拉伸<k+1>
...
```

相邻带元素集合相同时会自动合并成一次拉伸，所以带数是"该几段就几段"，不是固定几段。

**`log` 里每一行的 `segs` 是防伪标签，必须对上**：
`segs` 应等于「轮廓段数 + 本带要画的圆数」。
对不上说明圆被草图推理吞了（见坑 3），此时拉伸照样返回 ok，但孔会少——必须回头查，不能只看 `ok:true`。

成功时最后一行是 JSON：`{"ok":true,"volume_mm3":...,"log":[...],"files":[...]}`。
`ok:true` 但 `volume_mm3` 接近 0 = 拉伸没切到料，看 `log`。

体积还要能和阶段 3 的估算对上账：沉孔多切多少、盲孔少切多少，两笔加减必须能解释差值。
**解释不了就是还有别的几何变了**，不要用"容差"糊过去。

## 5 验收 `verify`（不做完不算完成）

四道门，顺序不能换。**第一关不过，后面的数字全都不算数。**

| # | 项 | 要求 | 怎么查 |
|---|---|---|---|
| 1 | **图注对账** | 图注每条：数量、孔径、通/盲、沉孔直径与深度、沉孔在哪一面 | `spec_verify.py`，末行必须 `问题 0 项` |
| 2 | 孔系对 DWG | 每个 DWG 圆都能找到对应孔 | `hole_audit.py`，末行 `问题 0 项` |
| 3 | 沉孔面 | 正面几处、反面几处，与图纸逐条一致 | `hole_audit.py` 末两行 |
| 4 | 深度 | 沉孔大直径段、盲孔的 z 起止 | `depth_check.py` + `log` 里各带 `segs` |
| 5 | 体积 / 质量 | 体积 ≤0.5%、质量 ≤1% | 输出 `volume_mm3` × 密度 |
| 6 | 包围盒 / 原点 | = 图纸总尺寸 × 板厚，左下角在 (0,0,0) | `spec_verify.py` 第二行 |
| 7 | 外形 | 有边框/窗口/孔/槽，非空件非乱线 | 看图，**正反两面各看一次** |

```powershell
& "$R\run.ps1" verify -Spec .\drawing_spec.json -Step .\out\<零件>.STEP `
                      -Segments .\part_segments.json -Part .\out\<零件>.SLDPRT -OutDir .\out
```

`spec_verify.py` 的输出**每一行都是一条图注**：

```
图注                                 要求     实得     判定
<n> × φ<d> 盲孔▽<深>                 ...     ...     OK
<n> × φ<d> 通孔 正面⌴φ<D>▽<深>        ...     ...     OK
<n> × φ<d> 通孔 反面⌴φ<D>▽<深>        ...     ...     OK

[汇总] 图注 <k> 条全部对上，问题 0 项
```

不通过时它会直接写出差异，不用人去猜：

```
<n> × φ<d> 盲孔▽<深>   <要求>   <实得>   FAIL
    实际 (x, y): φ<d> <z0>~<z1>   期望: φ<d> <z0'>~<z1'>
```

它只认三样东西：**孔径 + z 起止 + 有几个**。所以体积一致、质量一致、包围盒一致的模型，
只要沉的孔在错的那一面、或者盲孔打穿了，都会在这里现形。

**第一次用某个零件跑这条线时，顺手验一下这道门是不是活的**：

```powershell
& $PY "$R\scripts\diagnostics\gate_selftest.py" .\drawing_spec.json .\out\<零件>.STEP
```

它拿正确的模型做变异测试——盲孔加深 2mm、沉孔翻面、数量 +1、通孔改盲孔——每一项都必须被抓到，
末行 `[PASS] 验收器是活的`。一个"永远返回 0 问题"的检查器比没有检查器更危险，所以这道门本身也要被检查。

`hole_audit.py` 把 DWG 的每个圆和 STEP 里真实的孔壁对上，逐孔打印 `φ11 0.0~3.4 + φ6.6 3.4~8.0`
这种「直径 + z 起止」，末两行是 `正面沉孔 N 处 ['下(z=0.0)']   反面沉孔 M 处 ['上(z=8.0)']`。

判读要点，三条都要满足：

- **每个沉孔都有两个直径**（只出现一个 = 沉孔丢了，体积只差 0.3%，看体积永远发现不了）
- **大直径段必须贴端面**：`0.0~3.4` 或 `4.6~8.0` 才对；`2.0~5.4` 这种悬在中间 = 沉口没落到面
- **正面组和反面组不能落在同一个面**：两行都是 `下` 或都是 `上` = 只做了一个面

`depth_check.py` 按 z 分段归类，一眼能看出两套沉孔是不是真的分了面，以及盲孔是不是真的只到标注深度。

`views.ps1` 出两张正视图：`-后视看z0面.PNG`、`-前视看zmax面.PNG`。
两面必须**互补**：A 面四角是台阶孔、横排是直孔，B 面就反过来。两边一模一样 = 有一面没做。

`spec_verify.py` / `hole_audit.py` / `depth_check.py` 共用 `step_geom.py`（量孔的位置、直径、z 起止），
位置在 STEP 里量不准时不要改判据，先查 `step_geom.py` 的圆柱面边界解析。

**看图必须看两面**，不要只信数字，也不要只看一张 PNG——之前的「没画沉头孔」就是只看了一张图。
