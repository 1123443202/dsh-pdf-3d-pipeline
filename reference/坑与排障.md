# 八个坑与排障表

> 这些不是"注意事项"，是真实故障的完整记录。改脚本前先读一遍，别把已修的坑再踩回去。
> 一句话摘要见 `../SKILL.md` 的「八条静默失败」；为什么会长成这样见 `复盘-三次返工.md`。

## 八个会静默失败的坑（都踩过）

**1. SolidWorks 的 DXF 导入不能用。**
`InsertDwgOrDxfFile` 返回 True，草图里 41 个轮廓 `IsClosed` 全为真，但 `FeatureExtrusion3` 永远返回 null，
不报错。试过 5 种选中方式、参数矩阵、转换实体引用，全部失败；同一调用在手画草图上一次成功。
所以 `DwgBuild.cs` 改成解析几何、用 SketchManager 逐段重画——几何仍来自 DWG，只是不用 SW 的导入器。

**2. 同心圆让拉伸失效。**
同一草图里出现「同心、异径」的一对圆，基础拉伸必挂（二分：28 孔正常，32 孔即第 4 对同心圆出现就死）。
所以要把沉孔和它的内孔拆到不同 z 段，任何一段草图里都不许有同心异径对。

**3. 草图推理会吞圆，必须 `SketchManager.AddToDB = true`。**
`CreateCircleByRadius` 会对着已有孔/已有实体做推理，把圆合并或丢弃：实测 10 个圆只进去 3 个，
`sketch segs` 从 100 掉到 79，拉伸照样返回 ok，孔却没了。
`DwgBuild.cs` 的 `DrawAll()` 画之前置 `AddToDB = true`，画完还原。
**当年把这条误判成了「offset 拉伸会吞内轮廓」**——加上 `AddToDB` 后，带 `StartOffset` 的拉伸
画 10 个圆、进 10 个，完全正常。以后再遇到"孔没了"，先查 `segs` 数，不要先怀疑 offset。

**4. 体积一样，几何可以不一样。**
少 4 个沉孔只让体积差 0.48%；正反面沉孔对调，体积一模一样。所以**体积、质量、包围盒全都对，
也不能证明孔画对了**。唯一能证明的是逐孔量 z 起止（`hole_audit.py` / `depth_check.py`）。

**5. 图注里的沉孔，DWG 里没有那个圆。**
「4×φ6.6 完全贯穿 / 反面⌴φ11▽3.4」这一组，DWG 里只有 φ6.6 一圈圆，φ11 只存在于文字。
几何解析永远看不到它，模型就"只做了一个面"。由 `apply_spec.py` 按图注数量匹配后写进
`part_segments.json` 的 `back_counterbores`。**读图时要把每条沉孔标注的"正面/反面"抄下来**，
两条标注往往一正一反，别默认都在同一面。

**6. bulge 圆弧中点要取右法向。**
DXF 的 `bulge = tan(θ/4)`，中点 = 弦中点 + **右**法向 × `bulge×弦长/2`。用左法向会把 16 段圆弧全镜像，
轮廓自交，SW 不报错、只是拉伸失败。`part_segments.py` 已修正。

**7. 拿几何当验收基准，永远查不出漏读。**
这是最贵的一条：先按 DWG 建了模型，再拿 DWG 的圆去核对，得到「36 个孔全对、问题 0 项」，
而图纸要求的是「4 处正面沉孔 + 4 处反面沉孔 + 2 个盲孔」。**基准错了，验收越认真越自信地错。**
正确姿势：先 `drawing_spec.py` 抄图注，再建模，最后 `spec_verify.py` 拿图注核对。
自检脚本能查的只有"和基准一致"；基准是不是图纸要的，只能靠图注。

**8. 盲孔在图上和通孔一模一样。**
`2 × φ5 ▽5` 画出来只是一个 φ5 的圆，肉眼、DXF、STEP 都看不出它只深 5。
按通孔建完，体积只多 117.8 mm³（0.07%），质量、包围盒、孔数全部正常，
只有 `spec_verify.py` 的 `φ5 0.0~15.0` vs 期望 `0.0~10.0` 会把它抓住。
所以 `▽数字` 要当成**深度**读，不能当成又一处标注；`apply_spec.py` 会把它落到 `blind_holes`。

## 排障

| 症状 | 处理 |
|---|---|
| `spec_verify.py` 报 FAIL | 照它打印的「实际 … / 期望 …」改：数量不对查 `apply_spec.py`，z 不对查盲孔深/沉孔面，直径不对查 `part_segments.json` 的 r |
| `drawing_spec.py` 解析出的条数少于图纸 | 看 `unparsed`；多半是符号被当成独立行，参考"文字先聚行、符号再挂行"的做法 |
| `apply_spec.py` 报「可用光孔 0 个」 | 图注直径与几何对不上（图注 φ6.8、DWG 画 φ6.6），先确认哪个对，再改 |
| 拉伸失败 | 二分定位坏环：`powershell -NoProfile -ExecutionPolicy Bypass -File "$S\diagnostics\bisect.ps1" -Segments ".\part_segments.json"` |
| 尺寸对但沉孔没有台阶 | 跑 `hole_audit.py`，它会直接指出哪几个孔只有一个直径；再回去看 `log` 里各带 `segs` |
| 只有一面有沉孔 | 图注里「反面」那组有没有进 `back_counterbores`；`hole_audit.py` 末两行应一个是 `下` 一个是 `上` |
| 盲孔被打穿 | `blind_holes` 没写进去；`log` 里最后一带的元素数应比前面少（少的就是没跟过去的盲孔） |
| `segs` 比预期少 | `AddToDB` 没生效，圆被推理吞了 |
| 体积偏大、沉孔没切到 | 查 `-CounterboreDepth` 与各带厚度分配 |
| 挑错了外层 | 看 `outer loop` 是否等于图纸总尺寸；若是图框尺寸（如 1740×1188），说明外轮廓没闭合或有多层套框 |
| DWG 打开是空的 | AutoCAD 没开或权限级别不同；看同名 `.log.txt` |
| 所有 python 步骤无输出无报错 | 用的裸 `python`，换 `$PY` |
